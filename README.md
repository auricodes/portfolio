# Full-Stack Developer Portfolio – Aurora Pantaleo

## Overview

This repository contains a collection of full-stack web applications built during my learning journey in software engineering and backend development.

All projects are developed using the **MERN stack (MongoDB, Express.js, React, Node.js)** and are designed to progressively increase in complexity.

The goal of this portfolio is to demonstrate the development of real-world backend architecture, API design, database modeling, authentication systems, scheduling logic, and interactive user experiences.

Each project focuses on a different technical challenge and represents a step forward in my full-stack development skills.

# Portfolio Projects

The applications are presented in progressive order of complexity.

---

## 1️ Task Manager

First full-stack MERN application focused on authentication and protected APIs.

Main concepts:
- JWT authentication
- password hashing
- protected backend routes
- user-specific task management

Features:
- user registration and login
- create, update, delete tasks
- toggle task completion
- secure REST API

Folder: task-manager/

---

## 2️ Bug Tracker

Second MERN application focused on issue lifecycle management and relational data modeling.

Main concepts:
- issue tracking systems
- nested comments
- filtering logic
- structured REST APIs

Features:
- create and manage issues
- issue status lifecycle
- comment system
- priority labels and filtering

Folder: bug-tracker/

---

## 3️ Calend-U – Appointment Booking System

A scheduling application focused on dynamic availability and time-slot logic.

Main concepts:
- scheduling systems
- dynamic slot generation
- conflict detection
- backend utility functions

Features:
- define weekly availability
- generate time slots dynamically
- prevent double bookings
- booking interface for guests

Folder: calend-u/

---

## 4️ Booking-Flights – Flight Booking Simulation

A full booking flow simulation inspired by airline reservation systems.

This project focuses heavily on **user experience and multi-step booking workflows** while maintaining a full MERN architecture.

Main concepts:
- booking system logic
- passenger management
- dynamic UI states
- multi-step booking flow

Features:
- flight search
- flight details page
- passenger data input
- seat selection interface
- optional extras (baggage, pets, children)
- simulated payment system
- digital boarding passes
- video-based interactive UI

Folder: booking-flights/
